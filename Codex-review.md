# Codex review

Review of `52d55ac` on 26 November 2026. This is a living backlog for the current Google Docs workflow and the parts of the app that will carry forward. The separate backend owns authentication, student and teacher roles, role-specific features, and lesson management. Google Docs is the lesson source in use.

## Fix first

- [ ] **Prevent progress loss across tabs. Reproduced.** Two tabs recorded different answers, and a reload retained only the second tab’s answer. Each tab writes its entire in-memory snapshot. Store answers independently or perform a transactional update, then verify both answers survive a reload. [Progress store](src/entities/word/model/progress.ts#L108) · [Writes](src/entities/word/model/progress.ts#L137)
- [ ] **Separate language and document identities. Reproduced.** Spanish and Italian `la casa` share a streak. Selecting French `partir` can show a Portuguese conjugation. Removing a word in one document can remove it in another document with the same lesson date and number. Include the language in word and verb keys and the document ID in removal keys. Keep existing stored fields and migrate on read. [Word progress](src/entities/word/model/progress.ts#L162) · [Verb selection](src/features/conjugate-verb/ui/VerbsTab.tsx#L70) · [Lesson removals](src/entities/lesson/model/removed.ts#L41)
- [ ] **Reject stale sync responses. Reproduced.** An older response can overwrite the newer offline cache. A quiet refresh can supersede a manual refresh and leave the spinner running if the quiet request fails. Reject obsolete results before any cache write and track manual sync status independently. Apply the same identity check before lesson analysis updates the shared bank. [Document sync](src/app/App.tsx#L183) · [Lesson analysis](src/widgets/lesson-view/ui/LessonView.tsx#L128) · [Bank update](src/entities/lesson/model/bank.ts#L196)
- [ ] **Keep Reader results attached to the original text. Reproduced.** A lookup for text A can add its result to text B after the student switches. Reloading a German study can relabel its vocabulary as French. Carry the text ID through asynchronous actions and use the saved text’s language when restoring its study. [Reader actions](src/pages/text/ui/Reader.tsx#L131) · [Word lookup](src/widgets/word-menu/ui/WordActions.tsx#L154) · [Study normalization](src/pages/text/model/normalize.ts#L9)
- [ ] **Check the writing revision before marking it done or including a correction.** A controlled report probe returned the old correction and omitted the current draft. Code review also found that a check can tick completion for a draft edited while the request was pending. Match the result to the submitted revision. [Writing check](src/features/writing-task/ui/WritingTask.tsx#L98) · [Report contents](src/features/send-to-teacher/model/report.ts#L97)
- [ ] **Tell students when their work fails to save. Code review.** The storage helper ignores quota and blocked-storage errors, but Notes still shows “Saved on this device.” Return a save outcome for student-authored data and display it accurately. Consider a progress and notes export if browser-local storage will remain in use during the transition. [Storage](src/shared/lib/storage.ts#L11) · [Notes](src/widgets/lesson-view/ui/Notes.tsx#L30)

## Exercise and lesson correctness

- [ ] **Accept the intended grading variants and generate valid negative forms. Reproduced.** Portuguese `voce fala` is marked wrong instead of an accent error. French negative imperatives can produce `ne donne-moi pas` and `ne vas-y pas`. Add cases with and without subject pronouns, then handle imperative clitics before applying negation. [Grading](src/shared/lib/grade.ts#L39) · [French negation](src/entities/verb/lib/negation.ts#L11)
- [ ] **Keep each exercise in its target language.** A controlled Spanish multiple-choice question offered other languages as distractors. Gap Fill and Blitz also send mixed selections using the first word’s language, from code review. Filter distractors by target language and partition mixed selections before building or requesting a round. [Quiz](src/entities/lesson/model/quiz.ts#L161) · [Gap Fill](src/features/gap-fill/ui/GapFill.tsx#L28) · [Blitz](src/widgets/word-list/ui/WordBlitz.tsx#L32)

[Homework parser](src/entities/homework/model/homework.ts#L190) · [Homework launch](src/pages/home/ui/HomeworkCard.tsx#L175)

- [ ] **Keep repeated vocabulary visible in Downloaded lessons. Code review.** The shared bank keeps the newest occurrence of a repeated word. - [ ] **Check audio requirements before offering an exercise. Code review.** Check for a voice in the target language when creating dictation. ## Cost, performance, and structure

- [ ] **Make analysis refresh one-shot. Browser confirmed.** Visiting Grammar twice normally reuses the cache. After clicking **Read the lesson again**, switching to Words and back triggered a second forced request. A student report appended to the document also changes the analysis hash because the whole lesson body is hashed. Clear the forced refresh after use and derive the hash from teaching content. Include the effective translation target in cache identity when it falls back to the interface language. Preserve compatible cached results. [Extras refresh](src/widgets/lesson-view/ui/LessonView.tsx#L171) · [Lesson hash](src/entities/lesson/lib/document.ts#L73) · [Analysis cache](src/entities/lesson/model/bank.ts#L28) · [Translation fallback](src/shared/config/translation.ts#L16)
- [ ] **Check the Google Docs revision before inserting. Code review.** A write uses a numeric insertion position from an earlier read. If the document changes in between, content can go under the wrong lesson. Require the read revision when writing and recompute the position on a conflict. [Google Docs insertion](api/_lib/google.ts#L97)
- [ ] **Handle live-board delivery and reconnects. Code review.** Pictures are size-checked individually and then sent together. An oversized batch can fail silently. The saved scene drops deletion markers, so older peers can restore cleared strokes after reopening. Batch by encoded size, track delivery results, and keep enough revision information to reconcile deletions. [Board sending](src/pages/call/ui/BoardCanvas.tsx#L107) · [Board persistence](src/pages/call/ui/BoardCanvas.tsx#L259)
- [ ] **Measure and reduce initial JavaScript. Build baseline.** The production entry bundle was about 356 kB gzip before CSS. The Zoom chunk was about 992 kB gzip and loads on demand. Start with route-level loading for secondary pages. Measure the actual requests for Home, Lessons, and Call before setting route budgets. [App imports](src/app/App.tsx#L15) · [Zoom loading](src/pages/call/ui/ZoomCall.tsx#L43)
- [ ] **Reduce broad progress subscriptions and repeated scans.** The shell and word rows subscribe to the full snapshot. The shell also updates the global store during render. Move document selection outside render-time mutation and subscribe to the specific values each component uses. Stats scans all words once per lesson. Its aggregation took about 44 ms in a synthetic Node probe with 500 lessons and 15,000 words. Index by lesson in one pass and profile Downloaded lessons before deciding whether to paginate or virtualize large lists. [Shell](src/app/App.tsx#L235) · [Word rows](src/widgets/word-list/ui/WordsTab.tsx#L88) · [Stats](src/pages/stats/ui/Stats.tsx#L125)
- [ ] **Extract document sync from the shell and organize CSS as features change.** Preserve the existing FSD layers. Give sync one owner and a small observable state model. Keep shared theme and layout rules together while moving feature-specific styles closer to their components. [App shell](src/app/App.tsx#L114) · [Stylesheet](src/app/styles.css)
- [ ] **Set deadlines and measure costs at the existing API boundary.** Track latency, timeouts, cache hits, token use, and duplicate requests without recording student content. Coalesce identical in-flight analysis requests if measurements show repeat calls. [AI client](api/_lib/claude.ts#L53)
